## 2. 结论：Edge 是 regime 条件化的

1. **无条件 expectancy 勉强为正**（CI 下界 $6/笔），但由单一 regime 簇贡献——不可作为无条件 edge 的证据。
2. **条件化后符号清晰**：单边高实现波动 regime（4 月型）中 0–1DTE 为正；双向绞杀 regime（7 月型）中 0–1DTE 为负、2–7DTE 为正。
3. 亏损的三个可分解来源：(a) regime 翻转后继续使用 0–1DTE；(b) 频率升级；(c) 费用（7 月费用≈当月毛利）。
4. **候选持久 edge：2–7DTE 半导体/大科技多日行情**（三个月 +$132k、+$402/笔）——待样本外验证（§6 假设 H1）。

## 4. 规则（由数据推导，待 8 月数据校准阈值）

- **R1 武器默认档**：默认 2–7DTE。0–1DTE 仅当 regime gate 通过（VR 显著 >1 的趋势态 + regime score ≥ 阈值，初始 40）。
- **R2 频率硬顶**：每日新开仓 ≤ 8 笔（初始值；3 月 4.1/日盈利、7 月 25.1/日亏损）。超限只提示、不禁止（只读系统不控制下单），但当日档位标红。
- **R3 费用仪表盘**：月费用/|毛利| > 30% 标红（7 月该值 ≈ 100%+）。
- **R4 仓位缩放**：Moreira-Muir 逆方差缩放，档位 ×1.0 / ×0.5 / ×0.25，clip 到 [0.25, 1.0]。
- **R5 统计门槛**：任何"策略有效"结论要求 n ≥ 100 且 bootstrap CI 下界 > 0；展示"距离显著还差多少笔"。

### 5.1 【2026-08-20 增补】E-4 第 1 部分：gate 校准结果

协议：特征仅用当日开盘前可得信息（QQQ/SOXX/VIX 日线，yfinance）；训练 2026-04-01→06-30，样本外验证 07-01→08-20；目标变量为真实 0-1DTE 按入场日聚合的净盈亏。候选 gate 全部来自文献指定的组件与标准阈值（动量 0、MM 0.5、z 1.645），共 9 个组合，无网格搜索。

| gate | 训练 保留/屏蔽 | 样本外 保留/屏蔽 | 8/3 |
|---|---|---|---|
| VR-trending（单独） | +0 / +72,024 | +0 / −117,162 | 红 |
| TSMOM(Q&S)>0 | +19,982 / +52,042 | −64,757 / −52,405 | 红 |
| MM≥0.5 | +85,169 / −13,145 | −183,671 / +66,509 | **放行** |
| **TSMOM+MM（胜出）** | **+82,256 / −10,232** | **−22,992 / −94,170** | **红** |

结论：
1. **胜出组合 = QQQ 20d 动量 > 0 AND SOXX 20d 动量 > 0 AND MM scale ≥ 0.5**。样本外屏蔽了 80% 的 0-1DTE 亏损（−$94k/−$117k），**五个最差日（8/3、7/28、7/24、7/20、7/9）全部红灯**。已实现为 `src/regime/varratio.py::tsmom_mm_gate`（含 8/3 重放测试）。
2. **组件互补性**：8/3 当天 MM=0.54（单独放行），拦截靠 SOXX 动量 −10.85%；反之高波动日靠 MM。两族必须同时通过。
3. **日线 VR 判别力不足**（trending 判定过严，训练期全屏蔽）：Barbon-Buraschi/Baltussen 的伽马机制是日内现象，VR 发挥文献作用需要日内序列 → E-4 第 2 部分。
4. 诚实限制：样本外放行日仍净亏 −$22,992（gate 减损、不点金——与 Coval-Shumway 买方负 EV 基线一致）；组合在 9 个候选中选出，存在轻度选择偏差；VIX 缺两日数据，VIX 类 gate 结果受污染不采用。
5. 若 4/1–8/20 全程执行：0-1DTE 合计 ≈ +$59,264（实际 −$45,138），**gate 增量 ≈ +$104,402**，未使用任何事后信息。

### 5.2 【2026-08-20 增补】E-4 第 2 部分：日内 VR 与 R6 熔断模拟

**(a) 日内 VR（前 3 交易日 5 分钟 QQQ 收益的 VR(6)，开盘前可得）**：VR<1 的 22 天 0-1DTE 合计 +$64,646；VR≥1 的 16 天合计 **−$162,104**。方向与朴素直觉相反、与 Barbon-Buraschi 一致：日内动量态 = 做市商负伽马 = fragile。8/3 前三日 z\*=2.82 显著红。限制：仅 38 天样本（yfinance 5m 60 天上限）、漏 7/24 → **记为 H4，先每日记录实时验证，不入 gate**。

**(b) R6 熔断模拟**（当日已实现亏损触线禁止新开仓，真实序列重放）：$3k 救 +$59,840；**$5k 救 +$71,996**；$8k **−$27,760（负！深亏后反攻被锁）**；$12k +$31,777。非单调 → 估计量高方差，$5k 为暂定值。

**(c) 叠加测试**：gate 单独 +$59,264；gate+R6($5k) 叠加 **+$26,980（反而差 $32k）**——R6 拯救的灾难日 gate 已全拦，而 gate 放行日的深回撤反攻是利润来源（与 Daniel-Moskowitz 一致：好 regime 里对亏损减仓毁掉动量回收段）。**架构结论：gate 为主防线，R6 仅作灾备保险丝（宽线 ~$12k），不叠加。**

### 5.3 【2026-08-20 增补】投产级验收：PBO / DSR / HLZ 三道关的结果与决策

按量化行业投产标准对本仓信号做的正式验收（协议：Bailey-Borwein-López de Prado-Zhu 2015 CSCV；Bailey-López de Prado 2014 DSR；Harvey-Liu-Zhu RFS 2016）。样本：2026-04-01→08-20，T=94 个有 0-1DTE 交易的交易日。

| 检验 | 结果 | 通过线 | 判定 |
|---|---|---|---|
| PBO（CSCV，S=8，70 个分割） | **62.9%**（λ 中位 −1.12） | <50% | ❌ 未过 |
| DSR（TSMOM+MM，N=9 试验） | **49.0%**（SR₀=0.060 vs 实测 SR=0.058） | >95% | ❌ 未过 |
| HLZ t 检验：H1（2-7DTE 日度盈亏，88 天） | **t=1.79**（$2,219/天） | t>3.0 | ❌ 未过 |
| gate 差分（open 41 天 vs closed 53 天） | Δ=$3,415/天，Welch **t=0.77** | — | 证据弱 |

**专业解读（这不是"作废"，是分层）：**

1. **Alpha 主张与风控规则的证据门槛不同**——这是行业实践的核心区分。alpha 信号错误的代价是持续亏损，须过 t>3 / DSR>95%；防御性风控规则错误的代价不对称：误关损失有界（机会成本），误开损失无界（小账户的破产吸收壁）。Harvey-Hoyle-Korgaonkar-Rattray-Sargaison-van Hemert (JPM 2018) 对波动率目标化的结论正是此结构：夏普改善视资产而定、不总显著，但**左尾变薄在全资产类稳健成立**——这是 gate 的存在依据。
2. **gate 的组件是文献先验，不是从本数据挖出来的**：TSMOM（MOP 2012，58 市场约一个世纪证据）与逆方差缩放（MM 2017，20+ 因子）预先给定，本地仅在 9 个预定组合中选择。相对纯数据挖掘，有效试验数远小于名义值；但**"对该用户 0DTE 盈亏有效"这一本地主张确实未被证明**（PBO 62.9% 说的就是这个）。
3. **裁定**：
   - **gate 仅作防御部署**：只允许它**关闭** 0-1DTE，禁止任何"绿灯加仓"用法（那是 alpha 用法，证据未达标）。
   - **H1 状态 = promising / 证据不足**：t=1.79，按 √T 增长估算需 **T≈247 个交易日**（再 ≈7-8 个月实盘）才可能过 HLZ 线（前提是效应持续）。在此之前 2-7DTE 保持小仓位、以积累样本为目的。
   - **上线即监控（López de Prado 纪律）**：实盘每一天都是真样本外。面板逐日记录 gate 状态 × 实现盈亏；每季度用累积实盘记录重算 t / DSR / PBO。**预注册判据**：实盘 t>3 → H1 升格为可加仓的 alpha；gate 被关日的盈亏持续为正 → gate 降级废除。判据先写死，避免事后合理化。
